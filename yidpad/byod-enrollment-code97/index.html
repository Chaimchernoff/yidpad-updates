YidPad setup — build 97

At the tablet’s first Welcome screen, tap the same blank spot six times, connect Wi-Fi when asked, then scan.

Finish Android setup and create your private Parent PIN. Home starts empty. Tap + Add your first app, enter your Parent PIN, and choose the apps you want from the starter library.

Only apps you add download over Wi-Fi. Return Home at any time to see each app’s download progress. Apps become available as installation finishes. You can keep using ready apps while others download.

Android may ask for installation or security confirmation. App accounts and subscriptions are separate.
